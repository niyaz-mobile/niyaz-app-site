Niyaz Privacy Policy

Last updated: September 3, 2026

Niyaz is a spiritual journal application provided by Niyaz Mobile that processes data primarily on the user’s device. The application has no user account system, Niyaz-operated backend, or cloud synchronization.

Data stored locally

Prayer tracking, Quran goals, reading position, bookmarks, favorite surahs, per-surah reading positions, favorite hadith records, personal prayers, Spiritual Journal entries, dhikr counters, theme selection, and notification preferences are stored on the device. The application is configured to exclude its data from Android operating system cloud backup and device-to-device transfer.

Location and notifications

If the user optionally enables Device Location, approximate or precise device location may be used to calculate prayer times and the Qibla direction on the device. This information is not sent to a server operated by Niyaz. Users may instead enter a city or coordinates manually. Device Location first requests foreground access; on Android, background location is requested separately and progressively for automatic travel updates. If enabled, the operating system's low-power significant-location events refresh prayer times, future notifications, and related widget state on the device. Niyaz does not perform continuous, high-frequency GPS tracking or retain routes or location history.

Notification permission is optional. If exact alarm access is unavailable, the application uses inexact scheduling that may be delayed by the operating system.

If enabled by the user, the Lock Screen Spiritual Card can show the next prayer, a short daily-content excerpt, or the selected dhikr count in an Android or iOS Home Screen widget, a supported Lock Screen widget, a system notification, or a user-started Live Activity. Visibility is subject to device privacy settings. The iOS App Group and Android private app storage contain only a minimum snapshot and pending +1 Dhikr operations; coordinates, personal prayers, notes, and worship history are excluded.

External applications and services

The user chooses the destination application when sharing content. In the “Nearby Mosques” feature, after explicit confirmation, a search query and optional approximate coordinates may be sent to a map application or Google Maps web page. Those external services are governed by their own privacy terms.

Content sources

The bundled content uses Tanzil Uthmani 1.1 for the Arabic Quran text, QuranEnc Rowwad 1.0.4 for the Turkish translation, and the HadeethEnc Turkish v1.63.0 collection for 2,150 hadith records. Optional Tajweed colors use the bundled and validated Quran Foundation text_uthmani_tajweed data and are off by default. Reading activity is not sent to these sources. Quran Foundation attribution: “Quran data provided by Quran Foundation.” Content versions and other attribution information are available in the application’s “Content Sources” screen.

This release has no production Quran audio, streaming, audio downloads, or background-media data flow.

Advertising, analytics, and tracking

This release contains no advertising, AdMob, analytics, crash reporting, or user-tracking SDK. Religious usage activity is not sent by Niyaz to an external user profile.

Deleting data

The Settings > Reset data option deletes user preferences, SQLite records, and pending Niyaz notifications. Uninstalling the application also removes local application data from the device.

Product limitations

Niyaz does not provide medical, legal, professional advisory, or religious ruling services. The application’s store target audience is age 13 and over.
